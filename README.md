# cc-engine

The Command Center engine template: the repository a user copies ("Use this template", not a fork) to set up their own Command Center. It holds no foundation code - only pinned `@cc/*` dependencies and the user's business customisation (configuration, theme, UI widgets in declared slots, frameworks and packs, `connectors.lock`), and its AGENTS.md forbids the engine's own AI from changing code. Its content arrives with build task P1-18; the design lives in [cc-foundation/docs/design](https://github.com/merkensoft-iris/cc-foundation/tree/main/docs/design).
